# 策略运行

策略库保存可替换的 Python 插件；「策略运行」保存插件的运行实例。一个插件可创建多份实例，每份拥有自己的名称、参数、账户资金比例、数据源和调仓计划。支持联网模拟账户，不支持实盘实例。

## 开始使用

1. 在「券商与账户」「数据中心」配置自己的模拟账户和数据源。
2. 打开「策略运行」，创建实例，选择策略、账户、数据源及资金比例，保存。
3. 可先「检查连接」及「预览选股」。预览只读取与实例数据需求匹配的已有快照，不连接券商、不更新数据；休市时也可运行。首次使用或修改数据需求后，先在数据中心选择相应策略更新数据。预览显示数据日期、候选数量、策略内权重和折算到账户后的权重。
4. 「启动」会立即检查前置条件，在指定交易窗口建仓，之后按每日、每周或每月计划调仓。每天的数据更新时间和执行窗口均使用美东时间，自动处理夏令时和休市顺延。
5. 「执行一轮」对停止的实例运行一次，休市时等待下个可用窗口，完成后停止。已运行的实例执行后继续自己的计划。
6. 「详情与日志」显示最近选股预览、实际确认后的归属股数、参数和记录；也可按此实例的参数及计划导出 QuantConnect 回测代码。

选股预览不包含实时价格、下单股数或订单授权；执行时重新核对数据和券商报价、计算整股数量。修改参数、代码或确认持仓后，旧预览不再显示；最新一次预览失败时也不会显示此前的成功结果。单次连接检查或预览失败不会停止正在运行的实例；账户执行发生异常时，只暂停相关账户。

创建和保存不会开启交易。关闭网页不停止后台；停止后台或关闭服务时无法执行计划。服务器上的实例在服务重启后继续等待计划，未完成的账户批次会暂停，要求先核对，不会静默重发订单。

## 多策略共用账户

资金比例按整个账户净值分配，例如 60% MOM8 + 40% 科技股策略；比例总和不能超过 100%。策略本身的仓位仍受框架限制，例如策略投入其资金的 95% 时，60% 的账户预算对应最多 57% 的股票目标。

页面按账户显示已预留和可分配的资金比例。运行实例和停止但保留持仓的实例均占用分配比例；无持仓的停止实例不占用。这是配置中的资金预算，不是券商现金或购买力。保留持仓时修改预算也会检查总额，避免超过 100%。同一账户本轮内，使用相同数据源、范围、字段、历史长度及采集规则的实例共用一次数据更新；数据需求不同则分别采集。

框架只重算本轮到期实例；其他实例保留原有整股数量。同一股票的多个目标先合并，再向券商提交账户净差额。券商显示合并持仓，内部账本记录归属，确认成交后才更新。账户中原有的其他持仓单独保留，不自动卖出；这些持仓仍可能使合并目标超过账户总仓位或单股上限，此时暂停并显示原因。

停止实例会保留持仓，也保留其资金比例。已提交的订单继续核对；停止会阻止后续新委托，不会自动撤单或平仓。保留持仓的实例不能删除或更换账户。要退出持仓，应先把此实例策略调整为能够返回现金目标的规则，按计划执行并确认退出后再删除；不会把「停止」解释为清仓。

一个账户由策略实例管理后，旧的单策略自动计划和手动提交入口不能同时用于该账户。多个配置指向同一模拟账户时，应统一使用一个账户配置。归属股数出现非预期减少、账户变化或配置变化时暂停；不要手动修改 `runs/strategy_manager/state.json` 来跳过核对。

## 中断后的核对

「核对订单与归属」只查询已提交订单，不提交新的委托。若批次中仍有从未提交的订单，先停止此账户全部实例，再使用「结束未提交余单」；核对成交后按实际持仓分配归属，结束剩余计划。已有委托未确认时继续暂停。结束后的实际组合不一定达到原目标。

## 策略文件

策略库底部可下载 ZIP 策略包、上传新包、打开及编辑 Python 源码。ZIP 根目录包含：

```
strategy.py      # 实现 select(stocks) 或 select_with_context(stocks, context)
manifest.json    # type、kind=portfolio、entrypoint、输入 schema、数据需求等
README.md        # 可选，在策略卡中展开
```

建议下载现有包作为模板，修改 `manifest.json` 的唯一 `type`，保留匹配的类名和接口。上传会使用独立模块名，不覆盖原插件。编辑前停止全部自动计划和实例，并处理未完成批次；保存时验证 Python 语法、登记类名及文件版本，原代码备份在 `runs/strategy_manager/source-history/`。上传、编辑仅限已登录的工作台主人。

Python 插件具有程序用户的权限，只使用自己编写或审查过的代码。计算进程的时限和资源限制用于防止意外卡住，不是隔离恶意代码的安全沙箱。通用任意脚本、独立无限循环或自带下单函数不属于这个插件接口。

## 计算、日志及回测边界

每次实例选股在独立子进程运行，默认 60 秒，面板可调为 10–120 秒；输入上限 32 MB。Linux 增加 768 MB 地址空间及 60 秒 CPU 上限；Windows 使用计算超时和输入上限。涉及委托的执行进程不会因选股超时被强制结束。

最多管理 16 份实例。面板可保留最近 20–500 轮执行日志；账户意图账本、持仓归属和批次审计文件不会随日志清理。`runs/strategy_manager/` 为私有运行状态，不打包或上传 GitHub。

QC 导出单独回测该实例的策略与计划，不模拟其他实例对现金和账户的影响。账户级表现从「持仓与订单」中的实际净值记录观察；每个实例目前显示股数归属和执行记录，没有独立收益曲线。独立实例收益归因及多策略组合回测尚未实现。
