# 自动模拟交易

本次更新把手动选股、准备委托和执行流程接成可恢复的计划任务，保留手动操作。只支持具有日历、行情准备、模拟执行、订单核对能力的联网模拟券商插件；真实账户不在自动运行入口内。

## 操作

1. 启动后台，配置当前模拟账户和数据源。
2. 在「策略运行 → 单策略计划」核对绑定的策略、数据源、券商；展开「调仓设置」选择每日、每周或每月。与当前手动账户不一致时，先切到绑定账户才能核对或结束其订单；关闭原计划仍可直接操作。
3. 保存计划并开启自动运行。开启后立即检查账户、更新策略所需数据并选股；首轮建仓独立于常规调仓周期，正常交易时段内开始，休市或临近收盘时等待下一可用时段。之后按计划调仓，网页可以关闭。
4. 暂停交易用「关闭自动运行」；这会撤销后续提交许可，不撤销已经被券商接受的委托。用「核对订单状态」查询结果。

| 默认时间（美东） | 动作 |
|---|---|
| 开启时 | 检查当前模拟账户、数据与选股，显示首轮建仓时间 |
| 当前可用交易时段或下一交易日 09:35 | 核对实时行情与账户，执行首轮建仓；本期不重复调仓 |
| 每个交易日 06:00 | 按当前策略需求刷新数据，复用缓存 |
| 每月第一个交易日 09:35–10:35 | 准备一次冻结的委托批次并执行，持续核对原订单 |
| 每个交易日 16:20 后 | 只读核对本程序的未完成委托 |

日期使用券商提供的美国市场交易日历，自动处理夏令时。支持每日、每周指定工作日（休市顺延）以及每月 1–28 日起的首个交易日；准备时间和常规调仓开始时间以美东时间填写，面板的下次时间以本机时区显示。配置接口也支持 5–120 分钟窗口。首次建仓前仍会重新核对账户和行情，券商即时状态会阻止休市或提前收盘时发单。常规周期错过窗口不会追补；每日数据更新失败最多尝试三次，间隔十五分钟。首次检查失败会明确暂停，修复连接后重新开启。

## 重启与异常

- 开启状态与当前模块、账户、参数、代码版本绑定。相同版本重启会恢复检查；更改任何绑定内容会暂停，需重新核验和开启。
- 发单前先保存批次、数量和限价。重启仅核对或继续同一批次，不重新生成委托；继续执行必须在原交易日和计划窗口内。
- 已受理或部分成交会等待；不明、拒绝、撤销、账户持仓不符会暂停。不会自动撤单、重新定价或把未完成批次替换掉。
- 任何周期或首轮建仓存在未完成记录时先核对，不允许通过新周期绕过去继续下单。
- 点击只读核对后，只有账本确认没有未完成意图才能关闭被暂停的周期。关闭周期不代表目标仓位一定达成，也不会重新开启自动运行。
- 主动关闭后，可在原交易日、原窗口内重新开启，继续完全相同的冻结批次；模块、参数或代码变化均不允许这样恢复。
- 若决定结束这轮，先关闭自动运行，再点「结束未提交余单」。只有券商确认没有挂单，且原委托均为已成交或从未提交时，才将从未提交的意图记为放弃，并保留审计记录。不会撤销券商订单、补单或把放弃冒充成交。不明、部分成交、拒单或撤单仍阻止结束。
- 券商撤销或拒绝了委托时（例如限价单收盘过期），先在券商端确认原因，关闭自动运行后点「关闭已撤单/拒单」。程序会重新查询券商，只有券商仍报告相同的撤单或拒单状态，且没有状态不明、等待成交或部分成交的委托时，才把这些委托标为「已关闭」，同批次从未提交的计划一并结束，并写入审计记录。部分成交的股数按实际持仓保留；不会补单或撤单。之后的新交易日可以正常执行。
- 关闭开关会阻止下一笔新提交；正在传给券商或已接受的订单仍可能成交。检查记录后再决定下一步。

## 模块边界

策略负责数据需求、选股和目标权重；数据插件负责采集；券商插件负责真实日历、报价、模拟账户和委托查询。框架负责排程、任务互斥、账户校验和持久化。Portal 只操作这些接口，不内置股票名单、券商账号或策略规则。QuantConnect 回测模块保持独立。

沿用已有 MOM8 适配规则：总股票仓位 95%，八只等权，剩余现金保留。默认仍为月初调仓。周期选择属于框架设置，与策略插件独立；改成每日或每周后，回测也应使用相同周期。朋友原版的满仓、保留旧持仓不配平、空位买 BIL 等规则仍与本适配版不同。

## 部署边界

服务器升级器验证文件清单与 SHA-256、备份公开代码，并保留 secrets、configs、runs 和运行环境。OpenD 托管为可选步骤；必须在官方客户端完成登录并验证记住登录后才配置，不会嵌入密码或解锁真实交易。

离线测试覆盖日期、重启、重复订单、部分成交与停止许可；这些不能代替市场开放时的模拟委托验证。外部邮件、短信提醒和自动修复拒单没有在本次更新中启用，通知在 Portal 和服务器运行记录中查看。
