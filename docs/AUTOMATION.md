# 自动交易计划

自动计划将数据更新、策略计算、委托准备和执行接成可恢复的任务，保留手动操作。具有交易日历、行情准备、执行和订单核对能力的联网券商模块可接入同一流程，账户环境可以是券商模拟或实盘。实盘启动须取得服务器对具体绑定账户的独立授权；保存配置、切换模块或升级代码不会开启实盘。市场、币种、交易单位和时区来自模块，接口及授权要求见 [模块化交易执行](MODULAR_EXECUTION.md)。

## 操作

1. 启动后台，在「连接」中配置当前账户和数据源，确认账户环境与执行资格。
2. 在「策略运行 → 单策略计划」核对绑定的策略、数据源、券商；展开「调仓设置」选择每日、每周或每月。与当前手动账户不一致时，先切到绑定账户才能核对或结束其订单；关闭原计划仍可直接操作。
3. 保存计划并开启自动运行。开启后立即检查账户、更新策略所需数据并选股；首轮建仓独立于常规调仓周期，正常交易时段内开始，休市或临近收盘时等待下一可用时段。之后按计划调仓，网页可以关闭。
4. 暂停交易用「关闭自动运行」；这会撤销后续提交许可，不撤销已经被券商接受的委托。用「核对订单状态」查询结果。

下面是已有美股账户的默认计划示例，使用 `America/New_York` 时区；它不是其他市场的固定时间表。

| 示例计划 | 动作 |
|---|---|
| 开启时 | 检查绑定账户、数据与选股，显示首轮建仓时间 |
| 当前或下一个可用交易区间 | 核对实时行情与账户，执行首轮建仓；本期不重复调仓 |
| 每个交易日 06:00 | 按当前策略需求刷新数据，复用缓存 |
| 每月第一个交易日 09:35 起，最长 60 分钟 | 准备冻结的委托批次并执行，持续核对原订单 |
| 模块提供的当日最后收盘时间后 20 分钟 | 只读核对本程序的未完成委托 |

日期和可执行区间由券商模块提供，支持午休、提前收盘和连续交易市场，不用周一至周五猜测交易日。计划使用所选 IANA 时区并处理夏令时；面板的下次执行时间以本机时区显示。每周可选择周一至周日，休市按真实日历顺延；每月支持 1–28 日起的首个交易日。新市场必须提供明确的开闭市区间，旧的仅日期美股日历保留兼容解释。

执行窗口会在实际收盘或午休处截断；首次建仓临近区间结束时等待下一可用区间。当前表单提供 5–120 分钟窗口，配置接口支持 1–1440 分钟，但较长设置不能跨越日历中的休市区间。准备时间不得晚于计划执行时间。券商即时状态仍会在发单前再次核对。

常规周期错过窗口不会追补；每日数据更新失败最多尝试三次，间隔十五分钟。首次检查失败会明确暂停，修复连接后重新开启。

## 重启与异常

- 开启状态与当前模块、账户、参数、代码版本绑定。相同版本重启会恢复检查；更改任何绑定内容会暂停，需重新核验和开启。
- 发单前先保存批次、数量和限价。重启仅核对或继续同一批次，不重新生成委托；继续执行必须在原交易日和计划窗口内。
- 已受理或部分成交会等待；不明、拒绝、撤销、账户持仓不符会暂停。不会自动撤单、重新定价或把未完成批次替换掉。
- 任何周期或首轮建仓存在未完成记录时先核对，不允许通过新周期绕过去继续下单。
- 点击只读核对后，只有账本确认没有未完成意图才能关闭被暂停的周期。关闭周期不代表目标仓位一定达成，也不会重新开启自动运行。
- 主动关闭后，可在原交易日、原窗口内重新开启，继续完全相同的冻结批次；模块、参数或代码变化均不允许这样恢复。
- 若决定结束这轮，先关闭自动运行，再点「结束未提交余单」。只有券商确认没有挂单，且原委托均为已成交或从未提交时，才将从未提交的意图记为放弃，并保留审计记录。不会撤销券商订单、补单或把放弃冒充成交。不明、部分成交、拒单或撤单仍阻止结束。
- 券商撤销或拒绝了委托时（例如限价单收盘过期），先在券商端确认原因，关闭自动运行后点「关闭已撤单/拒单」。程序会重新查询券商，只有券商仍报告相同的撤单或拒单状态，且没有状态不明、等待成交或部分成交的委托时，才把这些委托标为「已关闭」，同批次从未提交的计划一并结束，并写入审计记录。部分成交的股数按实际持仓保留；不会补单或撤单。之后的新交易日可以正常执行。
- 关闭开关会阻止下一笔新提交；正在传给券商或已接受的订单仍可能成交。检查记录后再决定下一步。

## 模块边界

策略负责数据需求、选股和目标权重；数据插件负责采集；券商插件负责实际交易日历、逐标的报价规则、账户环境及委托查询。框架负责排程、任务互斥、账户校验和持久化。Portal 只操作这些接口，不内置股票名单、券商账号或策略规则。QuantConnect 回测模块保持独立。

当前 MOM8 实例的配置示例为总股票仓位 95%、八只等权、剩余现金保留，默认月初调仓；这些属于策略及实例配置，不是全平台固定仓位或标的数量。周期选择属于框架设置，与策略插件独立；改成每日或每周后，回测也应使用相同周期。朋友原版的满仓、保留旧持仓不配平、空位买 BIL 等规则仍与本适配版不同。

## 部署边界

服务器升级器验证文件清单与 SHA-256、备份公开代码，并保留 secrets、configs、runs 和运行环境。OpenD 托管为可选步骤；必须在官方客户端完成登录并验证记住登录后才配置，不会嵌入密码或解锁真实交易。

通用执行器目前采用现金覆盖、只做多的限价调仓模型，现有 MOM8、科技股策略和 QC 适配器使用日线美股输入。模块化接口不等于已实现所有市场、券商或保证金模型。离线测试覆盖多个时区、币种、交易单位、重启、重复订单、部分成交与授权撤销；这些不能代替具体账户的联网验收，实盘亦须独立验证。外部邮件、短信提醒和自动修复拒单没有在本次更新中启用，通知在 Portal 和服务器运行记录中查看。
