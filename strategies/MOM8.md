# MOM8 动量轮动

从美国上市普通股中筛选流动性充足、处于上升趋势的股票，以中期价格动量排名构建等权组合。通过行业上限控制集中度，并使用排名缓冲减少持仓更替。

## 选股规则

1. 股票池为美国上市普通股，排除 ADR、ETF 和 OTC 标的，不限制行业。
2. 市值介于 20 亿至 5,000 亿美元，未复权股价不低于 5 美元，最近 20 个交易日平均成交量不低于 100 万股。
3. 最新复权收盘价严格高于最近 200 个交易日的平均收盘价。
4. 按 12–1 动量由高到低排序：`动量 = 21 个交易日前收盘价 ÷ 252 个交易日前收盘价 − 1`，使用一致口径的复权价格。
5. 依次纳入排名靠前的股票，同一行业最多 2 只，形成最多 12 只股票的候选池。
6. 优先保留候选池中的现有持仓，再按排名补足至 8 只。每只目标权重为 11.875%，满额组合的目标股票仓位为 95%。候选不足时保留现金，不放大剩余股票权重。

动量得分决定排名，不直接决定资金比例。每次调仓按目标权重重新配平，包含继续保留的股票。调仓频率由运行计划指定。

## 参数

| 参数 | 默认值 | 含义 |
|---|---|---|
| `count` | 8 | 目标持股数量 |
| `weight` | 0.11875 | 单股目标权重，即 11.875% |
| `lookback` | 252 | 动量观察期，单位为交易日 |
| `skip` | 21 | 动量计算跳过的最近交易日数 |
| `trend_window` | 200 | 趋势过滤均线周期 |
| `keep_buffer` | 12 | 行业分散后候选池的最大数量 |
| `industry_limit` | 2 | 同一行业最多持股数 |
| `min_market_cap` | 2,000,000,000 | 最低市值，美元 |
| `max_market_cap` | 500,000,000,000 | 最高市值，美元 |
| `min_price` | 5 | 最低未复权股价，美元 |
| `min_average_volume` | 1,000,000 | 最近 20 个交易日的最低平均成交股数 |

## 数据要求

- 默认至少 253 根复权收盘价及最近 20 个交易日成交量。
- 未复权收盘价、市值、行业分类与稳定的标的标识。
- 同一决策时点的当前持仓名单，用于执行保留规则；缺失持仓名单不能视为空仓。

## 策略特征

不要求公司盈利，也不单独设置正动量门槛、止损或整体市场趋势过滤。价格高于均线是入选条件，未入选的原持仓退出目标组合。排名缓冲降低换股频率，但不取消目标权重配平。

价格复权方式、行业分类和股票池覆盖范围会影响排名；历史研究所用市值与分类须在当时已知。
