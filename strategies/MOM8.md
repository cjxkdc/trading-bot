# MOM8 · 框架适配版

来自朋友提供的 FriesTrader / Trading-Project-1-main 项目。注册名 `mom8`；实现为独立策略模块，不访问券商、网络或文件。源码使用许可见 [第三方声明](../docs/THIRD_PARTY_NOTICES.md)。

## 选股规则

- 在美国上市普通股中选取；排除 ADR、ETF、OTC，不限定科技行业。
- 市值 20 亿–5,000 亿美元，未复权股价至少 5 美元，最近 20 日平均成交股数至少 100 万。
- 需要 253 根完整日线；最新复权收盘价高于 200 日均线。
- 动量 = 21 个交易日前的复权收盘价 / 252 个交易日前的复权收盘价 − 1。
- 按动量排序，同一行业最多 2 只，先建立分散后的前 12 名缓冲池。
- 已持有且仍在缓冲池的股票优先保留，然后按排名填到 8 只。负动量不额外禁止；不要求公司盈利。
- 预览若没有账户上下文，只展示明确标注的“首次建仓示意”。回测与执行必须使用真实模拟组合或冻结且核对过的持仓；缺失持仓不是空仓。

## 与朋友部署版的区别（用户选择的框架适配）

| 项目 | 朋友 MOM8 部署版 | 本适配版 |
|---|---|---|
| 新持仓权重 | 12.5%，目标满仓 | 11.875%，8 只合计 95% |
| 已保留股票 | 不补仓、不削减涨起来的仓位 | 使用现有框架重新配平到目标权重 |
| 未用资金 | 缺额配置 BIL | 留现金，不购买 BIL |
| 调仓时间 | 每月 20 日或之后首个交易日，10:05 美东 | QC 默认月初首个交易日 09:35；工作台自动运行按保存的每日 / 每周 / 每月周期执行，首次建仓立即检查并等待可用交易时段 |
| 行业分类 | 部署版 SIC 四位代码 | Massive 研究用 SIC；QC 用 Morningstar 行业组 |
| 下单与费用 | 原项目专用限价、整股取整及费率 | 当前框架的执行检查及导出费用、滑点设置 |

这些差异会影响收益。适配版不是朋友的历史回测复现，也没有通过回测证明有效。保留了当前 95% 总仓位、19% 单股上限，不修改原有风险配置。

## 使用

1. Portal → 策略库 → **MOM8 · 框架适配版** → 保存策略配置。
2. 回测 → 导出回测代码。创建 QC Python 项目，将整个 `main.py` 粘贴进去运行，再导入结果。全美股历史请求明显多于科技股，云端运行时间取决于数据与节点资源。
3. 当前研究选股用数据中心的 **Massive**。策略声明全行业、市值、价格和成交股数，不请求财报；与科技股策略共用供应商、密钥及请求缓存。行情按交易日批量下载，策略的价格筛选与动量函数用于初筛，再按排名补查资料，直到分散后的前 12 名缓冲确定，或候选全部查完。选股规则、持仓保留与 95% 配平均不变。首次历史下载仍受套餐限速影响，可停止后复用有效日期缓存。只有点击「下载并预览」才开始采集。
4. 当前 Massive 价格仅拆股复权，市值及行业为当前查询资料。研究快照本身不能回测历史或直接提交券商订单，也不能宣称与 QC 的股息复权价格同口径。工作台的「一键测试并准备」会进一步检查账户、冻结持仓、读取券商报价并准备模拟订单；自动运行按相同执行要求检查。数据有缺漏时须检查覆盖情况。
5. 科技股范围快照不满足 MOM8 全行业需求。切换策略后需采集或导入匹配快照；不能将科技股子集当全市场运行。
6. 本地回放或模拟盘需要 **全美股动量执行快照**，包含 `portfolio_context`、实时买卖报价及完整股票池。执行前仍核对账户持仓，沿用现有框架防止重复交易和实盘禁用规则。本次没有执行券商交易。

CLI 独立配置为 `configs/mom8.json`，继承现有框架配置；不会把当前策略自动切走：

```powershell
.venv\Scripts\python.exe tools\build_quantconnect.py --config configs\mom8.json --out runs\mom8-qc-main.py
```

数据口径参考：[QuantConnect US Equity normalization](https://www.quantconnect.com/docs/v2/writing-algorithms/securities/asset-classes/us-equity/requesting-data)。
