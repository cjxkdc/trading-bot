# 双均线趋势

根据单一标的的短期与长期移动平均价格判断趋势，在持有和空仓之间切换。

## 交易规则

- 短期简单移动平均价严格高于长期简单移动平均价时，输出持有信号。
- 短期均线低于或等于长期均线时，输出空仓信号。
- 持有信号为 1，空仓信号为 0；实际资金比例由组合配置决定，不做空。

## 参数

| 参数 | 必填 | 含义 |
|---|---|---|
| `fast` | 是 | 短期均线窗口，按价格观测数计 |
| `slow` | 是 | 长期均线窗口，按价格观测数计 |

两个窗口均为正整数，且 `fast < slow`。使用日线时，窗口对应交易日数；策略本身不预设窗口数值。

## 数据要求

同一标的、同一价格口径且按时间排序的价格序列。生成信号前至少需要 `slow` 个完整观测值。

## 策略特征

均线信号具有滞后性，震荡行情可能产生反复切换。不包含止损、波动率目标或多标的分散规则。
