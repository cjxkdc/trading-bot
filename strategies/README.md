# 策略目录

| 策略 | 类型 | 核心规则 | 默认配置 |
|---|---|---|---|
| [MOM8 动量轮动](MOM8.md) | 多股票组合 | 中期动量、均线过滤、行业分散与持仓排名缓冲 | 8 只，每只 11.875% |
| [科技股盈利动量](TECH_PROFIT_MOMENTUM.md) | 多股票组合 | 科技股盈利与流动性筛选，再按中期动量排名 | 5 只，每只 19% |
| [等权对照](EQUAL_WEIGHT.md) | 多股票组合对照 | 按标的标识排序取样，固定等权 | 5 只，每只 19% |
| [双均线趋势](MOVING_AVERAGE.md) | 单标的择时 | 短期均线高于长期均线时持有，否则空仓 | 均线周期由参数指定 |
| [单标的动量](MOMENTUM.md) | 单标的择时 | 指定区间收益为正时持有，否则空仓 | 观察期与跳过期由参数指定 |
| [买入持有](HOLD.md) | 单标的基准 | 持续持有指定标的 | 无策略参数 |

组合策略的权重为目标值；实际持仓可能因价格变动、数量取整、交易成本和成交情况偏离目标。未分配资金保留为现金。单标的策略输出持有或空仓信号，资金比例由组合配置决定。

各策略说明记录其规则与默认参数，不代表已验证的收益表现。
