# 单标的动量

用指定观察区间的价格变化判断单一标的的趋势，可跳过最近一段数据，在持有和空仓之间切换。

## 交易规则

`区间收益 = 跳过期起点价格 ÷ 观察期起点价格 − 1`

- 区间收益严格大于 0 时，输出持有信号。
- 区间收益小于或等于 0 时，输出空仓信号。
- 持有信号为 1，空仓信号为 0；实际资金比例由组合配置决定，不做空。

以 `lookback = 252`、`skip = 21` 为例，比较 21 个观测值之前与 252 个观测值之前的价格。

## 参数

| 参数 | 必填 | 含义 |
|---|---|---|
| `lookback` | 是 | 动量观察期，按价格观测数计 |
| `skip` | 是 | 跳过的最近观测数 |

参数为整数，满足 `0 ≤ skip < lookback`。使用日线时，观察期对应交易日数；策略本身不预设窗口数值。

## 数据要求

同一标的、同一价格口径且按时间排序的价格序列，至少包含 `lookback + 1` 个完整观测值。

## 策略特征

使用绝对动量进行择时，不对多个标的进行相对排名。不包含止损、盈利筛选或波动率目标。
